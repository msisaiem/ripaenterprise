# M/S Ripa Enterprise — Portfolio Website

This website is based on the supplied M/S Ripa Enterprise Company Profile.

## Files
- `index.html` — complete responsive website
- `styles.css` — design and responsive styling
- `script.js` — mobile navigation and footer year
- `assets/ripa-logo.png` — supplied Ripa Enterprise logo

## Notes
- The website preserves the company profile's distinction between the registered address and the office address.
- The site states that more than 260 projects have been completed over the last 25 years; the current profile provides 24 representative project descriptions, which are presented in the project register.
- No project photographs were embedded in the supplied DOCX, so no project images were fabricated.
- The site is static and can be hosted on standard web hosting or GitHub Pages.

## Updated in this version
- Corrected the portfolio headline from 24 documented entries to 260+ completed projects.
- Clearly identifies the 24 displayed records as representative project descriptions rather than the total project count.
- Expanded the Founder & Heritage section using the full description from the supplied company profile.

## Suggested next phase
Add verified project photographs, official certificates/registration scans, downloadable company profile PDF, and a project-detail page for selected major projects.
